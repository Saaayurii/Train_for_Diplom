## О проекте

**РИСЖ** — веб-приложение для управления железнодорожной инфраструктурой, планирования маршрутов и мониторинга подвижного состава.

### Модули системы

- **Операционные исследования** — планирование и моделирование расписания поездов
- **Редактор инфраструктуры** — редактирование железнодорожной топологии
- **Карта маршрутов** — визуализация железнодорожной сети
- **Подвижной состав** — база данных локомотивов и вагонов
- **STDCM** — краткосрочный поиск пути
- **Расписание** — актуальное расписание движения поездов
- **Аналитика** — мониторинг системы в режиме реального времени
- **Маршруты** — ключевые железнодорожные направления России
- **Глоссарий** — словарь железнодорожных терминов
- **Поезда** — каталог поездов, изобретения и факты
